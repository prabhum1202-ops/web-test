# Roar Space Mens Collection

## Overview
Welcome to the Roar Space Mens Collection e-commerce platform. This project provides users with a seamless shopping experience for a wide range of men's clothing.

## Features
- **User Authentication**: Users can create accounts, log in, and manage their profiles.
- **Product Browsing**: Users can browse through various categories of men's clothing.
- **Shopping Cart**: Users can add items to their cart and manage their purchases.
- **Checkout Process**: Simple and secure checkout process with multiple payment methods.
- **Order Tracking**: Users can track their orders after purchase.

## Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/prabhum1202-ops/web-test.git
   ```
2. Navigate to the project directory:
   ```bash
   cd web-test
   ```
3. Install the necessary dependencies:
   ```bash
   npm install
   ```

## Usage
- Start the application:
   ```bash
   npm start
   ```
- Open your web browser and go to `http://localhost:3000` to see the application in action.
